# Mind Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an AI-powered interactive lecture mind-map drawer alongside the PDF viewer.

**Architecture:** A request module, strict parser, local cache, and dagre layout adapter feed a focused React Flow drawer. The drawer owns controls, rendering and PDF-page navigation.

**Tech Stack:** React 19, TypeScript, Tailwind CSS, @xyflow/react, dagre, lucide-react, node:test.

## Global Constraints

- Preserve the existing PDF viewer, notes, and tutor behavior.
- Require hierarchical JSON only; never process Markdown or HTML.
- Cache by document content plus requested scope/depth.
- Use custom nodes, animated smooth edges, minimap, background, controls, pan/zoom, and fit view.
