# Kiểm chứng với người học

Mục tiêu là kiểm tra thay đổi hành vi: học viên có tìm và xác nhận được kiến
thức trong PDF nhanh hơn khi dùng Slide2Study hay không.

Thư mục này chưa chứa kết quả người dùng thật. Cần mời đúng 5 người, thực hiện
theo `protocol.md`, điền `feedback-log.csv`, rồi chạy:

```powershell
python .\validation\analyze_feedback.py
```

Nếu còn ô trống, chương trình sẽ báo chưa đủ mẫu thay vì tạo số liệu giả.
